# 安装说明（3 分钟）

这是一个 DSH 桌面版的本地插件：把一段自定义 CSS 注入界面。压缩包里已经带好一套现成的「550W 壁纸」主题——背景是 550W 壁纸，面板半透明，文字保持可读。

---

## 第 1 步：解压到一个固定位置

把压缩包里的 `custom-css` 整个文件夹解压到：

```
%USERPROFILE%\dsh-plugins\custom-css
```

怎么找这个位置：打开资源管理器，在地址栏输入 `%USERPROFILE%` 回车（就是 `C:\Users\你的用户名`），新建一个名为 `dsh-plugins` 的文件夹，把 `custom-css` 放进去。

几点注意：

- 不要放在 `C:\Program Files` 这类需要管理员权限的目录；
- 路径里尽量别用特殊符号，放好后**不要再移动**（装好后登记的是这个路径，移动了要重新运行安装脚本）。

## 第 2 步：运行安装脚本

在 `custom-css` 文件夹里找到 `install.ps1`，**右键 → 使用 PowerShell 运行**。

如果窗口一闪而过，或者提示「禁止运行脚本」，打开 PowerShell 手动执行：

```powershell
cd "$env:USERPROFILE\dsh-plugins\custom-css"
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

脚本会自动完成四件事，并把每一步打印出来：

1. 在 DSH 的 profile 里登记插件目录（`link:` 依赖）；
2. 把 `@local/custom-css` 加进 profile 的 bundle 列表；
3. 在 `node_modules\@local` 下建一个指向插件目录的链接；
4. 往 profile 的 `cordis.patch.yml` 加一条插件条目。

常用参数：

| 参数 | 作用 |
| --- | --- |
| `-DryRun` | 只打印要改什么，不写任何文件 |
| `-DshHome "D:\某个路径\.dsh"` | DSH 配置目录不在默认位置时指定 |
| `-ProfileName myprofile` | 有多个 profile 时指定用哪个 |

## 第 3 步：完全退出 DSH，再打开

**完全退出**（包括右下角托盘图标里右键退出），然后重新打开 DSH。

如果设置里已经出现「自定义 CSS」但背景还没变，去 设置 → 插件 里把它关掉再打开即可，不用再重启。

## 第 4 步：确认插件是开启的

设置 → 插件 → 找到「自定义 CSS」，确认开关是打开状态。

---

## 怎么确认装好了

- 窗口背景变成 550W 壁纸，侧边栏和面板透出壁纸；
- 或者用浏览器打开 `http://127.0.0.1:<端口>/custom-css/status`（端口就是 DSH 窗口地址里的那个数字），能看到一段 JSON，其中 `cssRequests` 每隔一两秒 +1，说明页面里的样式正在轮询并生效。

## 想自己改

所有样式都在 `custom.css` 里，**保存后约 1 秒自动生效，不用重启、不用刷新**。

- 调壁纸明暗：改 `linear-gradient(rgba(4, 5, 9, 0.62), rgba(4, 5, 9, 0.75))` 里的两个数字（越大越暗）；
- 换壁纸：把图片放进 `assets/` 文件夹，再把 `url('/custom-css/assets/550w.png')` 换成你的文件名（png / jpg / webp / svg 都支持）；
- 调面板透明度：文件下半部分的 `--dsw-alias-bg-base`、`--dsw-alias-bg-layer-1` 等变量，里面的 `0.55`、`0.62` 就是透明度（越小越透明）。

## 卸载

- 右键 `uninstall.ps1` → 使用 PowerShell 运行，然后重启 DSH；
- 不想删的话，也可以只在 设置 → 插件 里停用「自定义 CSS」，随时再打开。

卸载脚本只撤销安装时的改动，不会删这个文件夹，确认不需要了直接把文件夹删掉即可。

## 常见问题

**1. 提示「没找到 DSH 的配置目录」**
先手动打开一次 DSH 桌面版，让它生成配置目录；如果 DSH 装在别的位置，用 `-DshHome "你的\.dsh 路径"` 指定。

**2. 提示「找到多个 profile」**
在 `%USERPROFILE%\.dsh\profiles` 下看看哪个是你的主 profile，然后 `-ProfileName 那个名字`。

**3. 插件列表里没有「自定义 CSS」**
先确认第 3 步真的完全退出了 DSH；仍然没有的话，把安装脚本的输出截图发过来。

**4. 其它样式生效了，但壁纸没出来**
检查 `assets\550w.png` 是否还在（解压时如果被杀毒软件拦过要重新放一次），以及 `custom.css` 里引用的是 `url('/custom-css/assets/文件名')` 这种形式。

**5. DSH 升级之后失效了**
一般不需要重装，设置 → 插件 里重新启用即可；如果 profile 被重置（插件列表整个变了），重新运行一次 `install.ps1`。

## 说明

- 这个插件只往 Web 界面注入一段 CSS，不联网、不改 DSH 本体、不收集任何数据；
